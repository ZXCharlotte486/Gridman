# 存货与成本审计

## 触发条件

用户要求执行存货审计、收发存勾稽、存货监盘底稿、存货计价、跌价准备、成本结转、成本倒轧、生产成本或主营业务成本测试时加载。

仅询问存货准则或成本核算原则时读取会计知识文件直接回答；未提供数据且不要求产出时，不假装已执行本 Workflow。

## 前置条件

必要材料：存货科目余额明细、总账/TB、收发存或库存台账、成本构成及结转数据。

推荐材料：盘点计划与盘点表、仓库清单、采购入库与销售出库记录、生产成本明细、成本计算表、存货库龄表、售价及期后销售资料。

开始前确认：

1. 主体、期间、仓库与存货类别；
2. 计价方法和成本核算流程；
3. 是否存在委托加工、寄存、在途、发出商品或第三方保管；
4. 盘点日与资产负债表日是否一致；
5. 是否存在呆滞、毁损、负库存或账实差异。

缺少监盘、原始单据或外部保管证明不阻塞账面分析，但相关存在性与权利义务程序必须标为未完成。

## 专业知识绑定

执行前读取：

- `references/knowledge/audit/audit_procedures.md`：存货循环、抽样、截止与实质性程序；
- `references/knowledge/accounting/accounting_core.md`：存货确认、计量和跌价；
- 按需读取 `references/knowledge/audit/journal_entry_analytics.md`。

如由总控调度，接收 `references/workflows/audit/trial_balance_and_lead_schedules.md` 的审定表、`references/workflows/audit/materiality_and_risk_assessment.md` 的风险参数和 `references/workflows/audit/journal_entry_testing.md` 的生产/采购异常凭证。

## 执行步骤

### 步骤1：建立存货审定表并勾稽

- 按原材料、在产品、库存商品、周转材料、发出商品等汇总；
- 勾稽存货明细、总账、TB 与报表；
- 记录未审数、调整、重分类和审定数；
- 输出《存货审定表》和《账账/账表勾稽表》。

差异未查清前不得强行调平。

### 步骤2：收发存与数量完整性检查

- 验证期初数量 + 本期入库 − 本期出库 = 期末数量；
- 对负库存、零数量有金额、数量有余额无金额、长期无变动项目单列异常；
- 检查仓库、存货编码和计量单位是否一致；
- 输出《收发存完整性检查表》。

### 步骤3：监盘程序准备与结果承接

- 根据金额、风险、库龄和地点选择重点监盘范围；
- 生成从账到实物和从实物到账的双向抽盘清单；
- 记录盘点差异、最后收发单号、毁损和代管情况；
- 盘点日非期末时设计前推/后推程序。

古立特可以编制监盘计划、抽盘表和差异汇总，但未实际观察盘点时不得填写“已监盘”或“账实相符”。

### 步骤4：计价测试

- 按企业既定计价方法抽取样本重算单位成本；
- 采购存货勾稽采购价、运费及可归属成本；
- 自制存货检查直接材料、直接人工和制造费用分配；
- 将重算成本与账面成本比较并汇总差异；
- 输出《存货计价测试表》。

计价方法变更或分配基础异常必须单列评价。

### 步骤5：生产成本与结转测试

- 勾稽材料领用、人工、制造费用与生产成本归集；
- 检查完工产品与在产品成本分配；
- 勾稽产成品入库和主营业务成本结转；
- 以期初存货 + 本期增加 − 期末存货倒轧本期结转，并解释与账面成本差异；
- 输出《成本归集与结转测试表》。

多借多贷或成本结转关系复杂时，可调用 `references/workflows/audit/journal_entry_testing.md` 的对方科目分析，但结果仅作线索。

### 步骤6：截止测试

- 围绕期末前后选取入库、出库、发票、签收和运输记录；
- 检查采购、销售和成本结转期间是否一致；
- 识别暂估入库、在途物资、发出商品和退货的跨期风险；
- 输出《存货收发截止测试表》。

缺原始单据时只列待核样本，不得判定截止正确。

### 步骤7：跌价准备测试

- 获取库龄、近期售价、销售费用、完工成本和处置资料；
- 识别毁损、过时、滞销、售价下降及合同取消项目；
- 按成本与可变现净值孰低重算；
- 检查转回和转销是否有依据；
- 输出《存货跌价准备测试表》。

无法取得售价或处置证据时，应列为估计不确定性和资料缺口，不得默认可变现净值等于账面成本。

### 步骤8：形成结论与调整建议

- 汇总勾稽、监盘、计价、截止、跌价和成本结转差异；
- 区分事实错报、判断差异和待补证事项；
- 将建议调整传递给 `references/workflows/audit/audit_adjustments_and_completion.md`；
- 输出《存货审计结论表》。

## 工具选择与授权

依次发现宿主表格/文档能力、已验证 MCP、本机 CLI。默认创建新底稿，不覆盖源台账。上传第三方、写入外部系统、修改库存记录或删除数据前必须确认。

能力不足时退回知识指引模式，提供收发存、计价、倒轧、截止和跌价模板，并明确未实际执行。

## 异常处理

| 异常 | 处理 |
|---|---|
| 存货编码或单位不一致 | 建映射表并保留原值，不确定项交人工确认 |
| 收发存不平 | 列示数量与金额差异，未查清不进入可靠计价结论 |
| 负库存 | 分仓库、日期追踪，判断系统时点或真实异常 |
| 盘点日非期末 | 执行前推/后推并核对期间收发 |
| 无近期售价 | 使用可验证替代证据并披露估计局限 |
| 成本分配规则缺失 | 列为内控和计量缺口，不自行发明分配基础 |

## 复核检查点

- [ ] 存货明细、总账、TB 和报表已勾稽；
- [ ] 收发存数量与金额异常均已解释或列入待办；
- [ ] 监盘实施状态如实记录，未把计划当结果；
- [ ] 计价方法、样本和重算过程可复核；
- [ ] 成本归集、完工分配和销售成本结转可勾稽；
- [ ] 截止测试覆盖期末前后并保留原始单据索引；
- [ ] 跌价测试有售价、成本和处置依据或已披露缺口；
- [ ] 调整建议可追溯且未覆盖源数据。

## 产出物

建议命名：`主体_期间_存货与成本审计_版本_日期`。

最低产出：存货审定表、收发存检查表、监盘计划/结果表、计价测试、成本结转测试、截止测试、跌价准备测试、差异与结论表。

## 跨 Workflow 协作协议

- 有项目数据底座时，接收并更新 `references/workflows/audit/trial_balance_and_lead_schedules.md` 生成的存货 Lead Schedule，不重复新建；独立运行且无底座时才创建。
- 本流程只输出调整候选，不正式写入审定 TB。候选至少包含 `project_id`、`period`、`entity`、`source_version`、`workpaper_ref`、`candidate_id`、认定、借贷方向与金额、证据状态、建议依据、`source_workflow` 和 `conclusion_owner`；正式过账仅由 `references/workflows/audit/audit_adjustments_and_completion.md` 执行。
- 监盘抽盘、计价或截止需要正式抽样时调用 `references/workflows/audit/audit_sampling.md`；本流程可以提出重大、异常或高风险定向项，但不得自行改变正式总体、样本编号和投射口径。
- 采购截止与 `references/workflows/audit/payables_and_purchases.md`、销售出库截止与 `references/workflows/audit/receivables_and_revenue.md` 共享样本。记录 `lead_workflow`、`sample_id`、`evidence_ref`、`cross_reference`、`conclusion_owner`，非主责流程引用并补充本循环判断，不重复取样。

## Mind 写入规则

仅在有跨会话价值时记录项目状态、输出索引和经确认的可泛化判断。不得把完整库存台账、仓位、供应商或未脱敏单据写入跨项目记忆。
