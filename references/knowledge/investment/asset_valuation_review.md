# 资产评估报告审核

> 定位：对已出具的资产评估报告做技术合理性复核，识别缺陷并分级，不重做评估
> 来源：资产评估报告审核实务蒸馏（古立特化重写）
> 覆盖：审核维度、估值参数阈值、关键假设检查、财务预测核查、法规合规、风险披露、ESG、三方交叉验证、QSC 评分、审核结论判定、AI 能力边界
> 性质：判断+实操

本文件是"复核他人评估报告"的主存放点，与评估师执业视角互补：
- 评估方法怎么做、何时法定评估、评估与会计/税务接口 → 详见：investment.md - 第九章 资产评估准则与执业要点
- 早期/硬科技无收益资产的情景与期权估值 → 详见：investment.md - 第八章 早期/硬科技公司估值
- WACC/DCF 建模机制 → 详见：investment.md - 第三章 DCF 模型

核心区别：investment.md 第九章解决"怎么评、该不该评"；本文件解决"这份评估报告靠不靠得住、哪里有问题"。审核只针对报告自身的技术合理性，不做报告外的业务判断。

## 一、审核总闸

### 审核定位与铁律

> 类型：规则
> 来源：评估报告审核实务
> 置信度：实务经验

[场景：拿到一份资产评估报告（企业价值、无形资产、数据资产等）要做技术复核]

审核按以下顺序推进，前序不清不进入下一步：

1. 识别报告类型和价值类型，据此选定适用的审核维度；
2. 提取报告基本信息与关键参数，固化到结构化清单；
3. 分维度审核，只对**确定存在的问题**生成审核发现（Finding）；
4. 做报告正文、评估说明、Excel 底稿的三方交叉验证；
5. QSC 五维评分并给出审核结论。

铁律：

- **证据优先**：每个 Finding 应当引用报告原文位置（页/段/行）和准则/规则依据，不得凭印象定性。
- **只审核不修改**：审核意见以发现和结论呈现，不改报告内容、不替评估师重估。
- **有明确问题才记录**：通过项只作检查记录，不生成 Finding；不得为凑数量把合规项写成问题。
- **不臆造证据**：未读取到的内容不得编造数字、段落或结论；参数缺失标"未提取/未披露"。
- **非最终意见**：审核结论是技术层面参考，不构成具有法律效力的鉴证意见；重大结论应由注册资产评估师独立复核。

### 报告基本信息提取（10 项）

> 类型：流程
> 来源：评估报告审核实务
> 置信度：实务经验

进入实质审核前，先提取并锁定 10 项基本信息，任一缺失标"未提取"：报告文号、评估机构、委托人、被评估单位、评估目的、评估对象、价值类型、评估基准日、评估方法、评估结论（最终评估值及选用方法）。

⚠️ 价值类型（市场价值/投资价值/清算价值/公允价值）决定后续判断口径——以财务报告为目的的评估通常是**公允价值**，不能用一般市场价值口径去套。

### 关键参数固化（防遗忘锚点）

> 类型：流程
> 来源：评估报告审核实务
> 置信度：实务经验

审核长报告前，先把核心参数从报告正文和评估说明中提取、固化为结构化清单，后续交叉验证时回读清单精准比对，不靠记忆：

至少固化 8 项核心参数——WACC、无风险利率 Rf、Beta（β）、市场风险溢价 MRP、特定风险 ε/Rs、永续增长率 g、资本结构 D/E、评估结论（收益法值/成本法值/净资产值）。每项记录：报告取值 + 来源位置。

⚠️ 参数固化是防"上下文过长导致漏检"的关键——先把参数落到清单，交叉验证阶段回读清单与底稿三方比对，不凭记忆回忆参数值。

## 二、报告类型与审核维度选择

> 类型：判断表
> 来源：评估报告审核实务
> 置信度：实务经验

[场景：先按评估对象定报告类型，再决定审核维度侧重，不套统一模板]

| 报告类型 | 审核侧重 |
|---|---|
| 企业价值评估 | 六维度全面审核（估值参数/关键假设/财务预测/法规合规/风险因素/ESG 行业），叠加三方交叉验证 |
| 无形资产/数据资产/碳资产/知识产权 | 侧重方法选择合理性与权属核查；收益预测的可持续性 |
| 珠宝首饰 | 侧重鉴定依据、品质分级与市场比准 |
| 生物资产 | 侧重行业特殊参数（生长周期、成活率、计价基础） |
| 金融工具 | 侧重定价模型选择、可观察输入层级（公允价值层次） |

新增报告类型时，按"评估对象特殊性 → 该类型最易出错的参数/假设"补充侧重，不改动通用七维度框架。

## 三、七个审核维度检查点

> 本章是审核的核心资产——量化阈值和检查点。P 级：P0=影响评估结论有效性的重大问题；P1=影响报告质量可信度；P2=优化建议。

### D1 估值参数审核

> 类型：判断表
> 来源：评估报告审核实务
> 置信度：实务经验
> 关联：investment.md - 第三章 DCF 模型（WACC/终值机制）

| 检查点 | 审核要点 | P级 |
|---|---|:---:|
| WACC/折现率合理性 | 是否在行业合理范围？构成（Rf + β×MRP + Rs）是否完整、各分量有据？ | P1 |
| 永续增长率 g | 是否超过长期 GDP 增长率（通常 2%~3%）？是否超过 WACC？与行业是否匹配？ | P1 |
| Beta 系数 | 计算周期是否合理？可比公司选择是否恰当？是否做了财务杠杆的卸载/加载？ | P1 |
| 特定风险 Rs/ε | 是否有量化依据？子项构成（规模/财务/法律风险等）是否清晰？ | P2 |
| 可比公司 | 数量是否≥3 家？行业匹配度、业务相似性如何？ | P1 |
| 敏感性分析 | 是否提供？是否覆盖 WACC/毛利率/收入增长率/税率等关键变量？ | **P0** |
| 永续期口径一致性 | 永续期资本性支出、折现率、资本结构、增长率是否与预测期一致？若有差异，是否论证合理性？ | **P0** |

⚠️ 硬规则：永续增长率**必须** < WACC，且通常**不得**超过长期 GDP 增速。收益法作为最终结论却**完全缺失敏感性分析**的，直接判 P0。

### D2 关键假设审核

> 类型：判断表
> 来源：评估报告审核实务
> 置信度：实务经验
> 关联：investment.md - 第九章（方法选择）

| 检查点 | 审核要点 | P级 |
|---|---|:---:|
| D/E 资本结构假设 | 若 D/E=0 且涉及收购场景，是否合理？永续零负债是否符合经营规律？ | **P0** |
| 税收优惠续期假设 | 是否考虑优惠到期后税率恢复风险？有无分段税率或敏感性分析？ | **P0** |
| 在建工程投产假设 | 未完工在建工程若纳入收益预测，是否做了竣工延迟的敏感性分析？ | **P0** |
| 预测期长度 | 是否覆盖投资回收期？化工、制造等重资产行业建议 5~7 年 | P2 |
| 短期数据依赖 | 收入预测是否仅依赖不足 6 个月的实际数据？ | P2 |
| 循环论证风险 | 成本-售价传导关系是否量化？价格预测是否有独立依据？ | P1 |
| 参数逻辑一致性 | 高 WACC 是否搭配了高增长？毛利率假设是否与竞争环境矛盾？ | P2 |
| 控股权溢价 | 评估目的为收购/合并时，是否分析控股权溢价或折价的影响？ | P2 |

### D3 财务预测审核

> 类型：判断表
> 来源：评估报告审核实务
> 置信度：实务经验

| 检查点 | 审核要点 | P级 |
|---|---|:---:|
| 收入增长率 | 与历史期对比偏差是否≤10%？与行业平均对比偏差是否≤5%？ | P1 |
| 利润率趋势 | 毛利率/净利率走势是否合理？与历史趋势是否一致？ | P1 |
| 营运资金变动 | 测算是否完整？与收入增长是否匹配？ | P2 |
| 资本性支出预测 | 是否与产能规划一致？维护性资本支出是否充足？ | P2 |
| 多方法结论差异 | 采用两种以上方法时，若结论差异率 >30% 是否做了量化差异拆解？ | P1 |

### D4 法规合规审核

> 类型：判断表
> 来源：评估报告审核实务 + 资产评估准则体系
> 置信度：实务经验
> 关联：investment.md - 第九章（法定必须评估的情形/方法准则）

| 检查点 | 审核要点 |
|---|---|
| 法规引用正确性 | 引用的准则/文号是否准确、现行有效？（引用前须核实，不确定标"待核实"，不臆断） |
| 方法选择合规 | 是否采用至少 2 种方法？未用方法是否说明原因？ |
| 评估假设完备性 | 是否包含持续经营、公开市场、交易假设等基本假设？ |
| 特别事项披露 | 产权瑕疵、未决诉讼、抵押质押等是否充分披露？ |
| 评估结论合规 | 结论是否包含价值金额和货币单位？有效期是否声明？ |

### D5 风险因素审核

> 类型：判断表
> 来源：评估报告审核实务
> 置信度：实务经验

| 检查点 | 审核要点 | P级 |
|---|---|:---:|
| 产权瑕疵 | 无证房产、违章建筑是否披露？对评估值的影响是否量化？ | **P0** |
| 法律风险 | 未决诉讼、行政处罚风险是否识别并量化影响？ | P1 |
| 或有事项 | 担保、保证等或有负债是否披露？ | P2 |
| 资产限制 | 抵押、质押、查封是否披露？ | P2 |
| 数据可靠性 | 关键数据来源是否可验证？ | P1 |
| 无证资产汇总 | 存在未办证资产时，是否汇总披露面积、账面值和评估值占比？ | P2 |

### D6 ESG 与行业特殊因素

> 类型：判断表
> 来源：评估报告审核实务 + IVS 2025
> 置信度：实务经验
> 关联：esg.md - ESG 因素识别

| 检查点 | 审核要点 |
|---|---|
| ESG 因素 | 气候变化物理风险（极端天气、海平面上升）、转型风险（碳税、环保政策）是否考虑？ |
| 行业特殊风险 | 政策风险、技术迭代风险、供应链风险是否分析到位？ |
| 行业竞争格局 | 市场份额、竞争排名、主要竞争对手是否分析？ |

### D7 交叉验证（三方参数比对）

> 类型：判断表
> 来源：评估报告审核实务
> 置信度：实务经验

对同一参数在报告正文、评估说明、Excel 底稿三个来源间比对，任一不一致即标 Finding：

| 检查点 | 审核要点 | P级 |
|---|---|:---:|
| WACC/折现率比对 | 报告正文 vs 评估说明 vs Excel 底稿三方是否一致；Excel 实际折现计算值与报告声明值是否一致 | **P0** |
| Beta 数据源比对 | 报告声称的数据源与底稿实际数据源是否一致；β 值是否一致 | **P0** |
| 核心财务数据比对 | 营业收入/净利润/净资产在三个来源间是否一致 | P1 |
| 评估结论比对 | 收益法/成本法结论在三个来源间是否一致；差异率是否与报告声明一致 | P1 |
| Rf/g/D/E/ε 比对 | 各关键参数在三个来源中取值是否一致 | P1 |
| 实时参数比对 | 报告引用的评估基准日 LPR、国债收益率、汇率中间价、股指等，与官方来源当日数据是否一致 | P1 |
| 上一版评估对比 | 底稿存在前次评估数据时，对比两次关键参数变化是否有合理解释 | P2 |

⚠️ 涉及评估基准日当天的 LPR、汇率中间价、国债收益率、股指收盘价等变动频繁的公开参数，应回官方来源（央行、外汇交易中心、交易所）核对当日数值；无法联网核实时标"未验证实时参数"，不臆断一致。

## 四、QSC 五维质量评分

> 类型：判断表
> 来源：评估报告审核实务
> 置信度：实务经验

| 维度 | 权重 | 评级标准 |
|---|:---:|---|
| 形式完整性 | 15% | A≥90，B≥75，C≥60，D<60 |
| 逻辑自洽性 | 20% | 同上 |
| 数据可靠性 | 25% | 同上 |
| 披露充分性 | 15% | 同上 |
| 合规符合性 | 25% | 同上 |

综合评级：加权平均后 ≥90→A，≥75→B，≥60→C，<60→D。每个维度的扣分**必须**附扣分依据（对应到具体 Finding），不得只给分不说理由。

## 五、审核结论判定

> 类型：规则
> 来源：评估报告审核实务
> 置信度：实务经验

按 Finding 的 P 级数量判定总体结论：

| 条件 | 结论 |
|---|---|
| P0 数量 > 0 | **不通过** |
| P0=0 且 P1 数量 ≥ 3 | **有条件通过** |
| 其他 | **通过** |

每条 Finding 应当满足三段式质量标准，不达标标"⚠️ 描述不足"：

1. **问题描述**：含具体事实（报告原文引用、页/段位置、涉及金额或参数值）+ 后果量化；
2. **依据**：至少引用一条准则/法规全称与条款（引用前核实，不确定标"待核实"，不编造文号）；
3. **修改建议**：逐条编号、具体可执行，不写"建议加强""建议完善"这类空话。

## 六、AI 能力边界

> 类型：规则
> 来源：评估报告审核实务 + IVSC AI 应用原则
> 置信度：实务经验

审核评估报告时，**必须**向用户明示以下边界，不得越界宣称：

能做：文本完整性审核、逻辑一致性审核、方法规范性审核、合规性审核、参数三方比对、准则解读与检查清单。

不能做（应当明确告知）：

- **数值计算验证**：不独立重算 WACC、不跑蒙特卡洛/贝叶斯推断——只能核对报告已给出的计算是否前后一致。
- **模型收敛性检验**：不验证统计模型的数学收敛性。
- **数据真实性核验**：不核实外部数据的真实性，只核对来源是否可追溯、三方是否一致。
- **现场调查核实**：不替代现场勘查、访谈、函证。
- **法律效力判断**：不出具有法律效力的鉴证意见。
- **权属真实性核验**：只核查文件形式完备性，不核实权属真实性。

⚠️ IVSC AI 原则：AI 辅助审核**必须**披露工具性质、使用范围和局限；重要结论建议由注册资产评估师独立复核。这与古立特"承认边界""不站队、不替代专业判断"两条铁律一致。
