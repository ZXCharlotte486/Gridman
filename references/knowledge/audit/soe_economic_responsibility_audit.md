# 国有企业经济责任审计

> 定位：国企领导人员经济责任审计的标准流程、专项模块选择、评价与责任界定
> 来源：中天恒经济责任审计实务指南 + 两办新规（中办发〔2019〕45号）体系（古立特化重写）
> 覆盖：8步流程、24专项模块、模块适用矩阵、审计评价7维度、直接/领导责任界定、三个区分开来、制度依据分层
> 性质：实操+判断

本文覆盖“对国企领导人员任职期间经济责任履行情况”的专项审计，区别于企业财务报表审计与一般内部审计。企业内审通用框架见 internal_audit.md；政府/行政事业单位收支审计见 internal_audit.md 第八章。

---

## 一、审计定位与边界

### 经济责任审计的对象与目标

> 类型：规则
> 来源：中办发〔2019〕45号 + 内审准则2205号
> 置信度：实务经验
> 关联：internal_audit.md - 3.2 经济责任审计

[场景：接到国企领导干部离任/任中审计委托，先定清审计对象和评价边界]

经济责任审计的对象是**领导人员任职期间经济责任的履行情况**，不是对企业财务报表整体发表意见。核心目标是查清并评价：重大经济决策、财政财务收支、国有资产管理、内控建设与执行、廉洁从业五个方面的责任履行。

边界铁律：

- **应当**聚焦经济责任履行，不超越被审计领导的法定职责范围。
- 对审计中**未涉及的事项不作评价**，不得凭印象给总体结论。
- **应当**获取充分审计证据支撑每一条评价，坚持权责一致、既看问题也看成绩。

### 判断标准来自制度依据（三级体系）

> 类型：规则
> 来源：经济责任审计实务
> 置信度：实务经验

审计判断标准 = 制度依据。没有制度依据的事项**不得**进入实质查证，也**不得**据以定性。制度依据分三级，逐级向下具体：

| 层级 | 内容 |
|---|---|
| 国家级 | 党中央、国务院、财政部、专业部委政策（如三供一业移交、混改、国资监管规定） |
| 上级级 | 上级党委政府、主管部门、集团公司的具体管理办法与操作细则 |
| 本单位 | 被审计单位据上位规定制定的内部管理制度 |

⚠️ 定性时**应当**引用到具体层级的具体条款；找不到精确条款时匹配上位法原则性规定，并标注“依据需人工核验”，**不得**编造文号。

## 二、八步标准审计流程

> 类型：流程
> 来源：经济责任审计实务指南（第2章提炼）
> 置信度：实务经验

任何经济责任审计按以下八步推进，制度依据（步骤1）与查证（步骤6）不可跳过：

```
1 查制度依据 → 2 取考核目标 → 3 定审计内容 → 4 风险评估 →
5 完善计划 → 6 审计查证 → 7 撰写报告 → 8 跟踪整改
```

| 步骤 | 核心动作 | 关键产出 |
|---|---|---|
| 1 查制度依据 | 按三级体系找被审事项的判断标准 | 制度依据清单 |
| 2 取考核目标 | 取任期经营业绩责任书、上级任务书 | 考核指标 + 任务书 |
| 3 定审计内容 | 按五维度确定内容与重点 | 审计内容清单 + 重点 |
| 4 风险评估 | 了解部门/流程/内控/决策/计划，评估风险定策略 | 风险等级 + 审计策略 |
| 5 完善计划 | 据范围、风险、重点编制审计方案 | 审计方案 |
| 6 审计查证 | 非财务7项通用程序 + 财务收支审计 + 专项模块 | 各模块工作底稿 |
| 7 撰写报告 | 四要素成文 | 审计报告 |
| 8 跟踪整改 | 沟通、整改台账、制度完善 | 整改台账 |

### 步骤3：五维度确定审计内容

> 类型：判断表
> 来源：经济责任审计实务
> 置信度：实务经验

| 维度 | 查什么 |
|---|---|
| 应做未做 | 是否按党和国家、上级要求履行职责 |
| 制度齐备 | 内控制度是否健全完善、有效执行 |
| 怎么做的 | 运作是否合规 |
| 效果如何 | 是否实现预期目标（经济/社会/民生/环境） |
| 财务合规 | 收支是否纳入预算、专款专用、有无舞弊 |

### 步骤6：查证的三个层次

> 类型：流程
> 来源：经济责任审计实务
> 置信度：实务经验

**6.1 非财务查证（7项通用程序）：** 分析决策/计划/执行/完成资料 → 取职能部门验收、审计、绩效评价报告 → 走访座谈了解基层 → 实地察看项目 → 访谈受益人核实目标达成 → 通过其他职能部门了解（如环保违法记录） → 咨询专家。

**6.2 财务收支审计：** 资产/资金管理规范性、专款专用、资金发放是否合条件标准、有无虚假列支或项目名义腐败、收支真实完整准确、经济效益评估。

**6.3 专项模块查证：** 按被审计单位业务范围从24个专项模块中选适用者执行（见第四章）。

## 三、审计评价与责任界定

### 审计评价7维度

> 类型：判断表
> 来源：中办发〔2019〕45号
> 置信度：实务经验

评价严格限制在审计查证范围内，逐维度写实：

1. 贯彻执行党和国家经济方针政策、决策部署情况
2. 发展战略规划的制定、执行和效果
3. 重大经济事项的决策、执行和效果
4. 法人治理结构、内部控制制度
5. 财务真实合法效益、风险管控、境外资产、生态环境保护
6. 落实党风廉政建设责任和遵守廉洁从业规定
7. 以往审计发现问题的整改情况

评价可用写实评价或“好/较好/一般/较差”量化分等；评价方法用目标责任法、历史参照法、业绩比较法，纵向（上任 vs 离任）+ 横向（同行业相近单位）对比。

### 责任界定：直接责任 vs 领导责任

> 类型：判断表
> 来源：中办发〔2019〕45号
> 置信度：实务经验

责任界定**必须**基于职责分工，按行为与后果的因果关系判定，不得笼统归责：

| 责任类型 | 适用情形 |
|---|---|
| 直接责任 | 直接违反法律法规、直接决策违规、直接插手干预、失职渎职造成后果 |
| 领导责任 | 管理监督不到位、制度不健全、未履行“一岗双责”等 |

### “三个区分开来”

> 类型：规则
> 来源：中办发〔2019〕45号
> 置信度：实务经验

定性和追责时**应当**区分：

- 主观故意 与 客观过失
- 改革创新失误 与 失职渎职
- 一般性问题 与 严重违纪违法

⚠️ 对改革创新中的探索性失误，不简单等同于失职渎职；但**不得**以“改革创新”为名掩盖主观故意的违纪违法。

## 四、24个专项审计模块

> 类型：判断表
> 来源：经济责任审计实务指南（第3-26章）
> 置信度：实务经验

每个专项模块遵循统一结构：基本概念 → 审计目标 → 审计依据 → 审计内容 → 审计程序 → 审计建议 → 评价与责任界定。按类归纳如下。

### 战略与政策类

| 模块 | 核心审计标的 |
|---|---|
| 贯彻执行党和国家经济方针政策、决策部署审计 | 政策传达落实、任务指标完成、决策部署执行效果 |
| 企业发展战略规划审计 | 规划制定程序合规、执行有效、目标达成 |
| 重大投资项目决策、执行和效果审计 | 投资决策程序、项目执行合规、投资效果 |
| 生态环境保护情况审计 | 环保法规执行、污染治理、生态修复、环保投入 |

### 境外业务类

| 模块 | 核心审计标的 |
|---|---|
| 中央企业境外投资审计 | 境外投资决策程序、执行、效果、风险管控 |
| 中央企业境外国有资产监督管理审计 | 境外资产登记、处置、安全完整、监管制度执行 |

### 改革重组类（上市公司国有股权相关）

| 模块 | 核心审计标的 |
|---|---|
| 混合所有制改革审计 | 改革方案审批、资产评估、产权交易、职工安置 |
| 上市公司股份证券交易系统转让审计 | 转让合规、信息披露、价格公允 |
| 上市公司股份公开征集转让审计 | 公开征集程序、受让方资质、转让价格 |
| 上市公司股份非公开协议转让审计 | 协议转让条件、审批程序、价格合理 |
| 上市公司股份无偿划转审计 | 划转条件、审批权限、资产完整 |
| 受让上市公司股份审计 | 受让决策、资金来源、信息披露 |
| 控股上市公司吸收合并审计 | 合并方案、债权人保护、资产评估 |
| 控股上市公司发行证券审计 | 发行方案审批、发行程序合规 |
| 与上市公司资产重组审计 | 重组方案、关联交易、资产定价 |

### 业务循环类

| 模块 | 核心审计标的 |
|---|---|
| 销售和收款循环审计 | 收入确认、应收账款、信用管理、舞弊风险 |
| 采购和付款循环审计 | 采购合规、供应商管理、付款审批、舞弊风险 |
| 资金活动审计 | 资金管理、融资合规、担保业务、资金安全 |

### 治理与合规类

| 模块 | 核心审计标的 |
|---|---|
| 劳动用工和收入分配审计 | 用工合规、薪酬制度、绩效考核、社保缴纳 |
| 企业法人治理结构审计 | 三会及经理层履职、“三重一大”决策 |
| 全面风险管理及合规管理审计 | 风险识别评估、合规审查、重大风险事件应对 |
| 内部控制体系建设与监督审计 | 内控设计有效性、执行有效性、缺陷整改、评价报告 |
| 党风廉政建设责任和廉洁从业审计 | “两个责任”落实、廉洁从业、八项规定、利益冲突 |

### 模块适用矩阵（按被审计单位类型选模块）

> 类型：判断表
> 来源：经济责任审计实务
> 置信度：实务经验

先定被审计单位类型，再据业务范围选必审 + 选审模块，不逐个照搬：

| 被审计单位类型 | 必审重点 | 选审（按业务） |
|---|---|---|
| 集团总部 | 政策落实、战略规划、重大投资、法人治理、风险合规、内控、廉政 | 环保、境外、混改 |
| 二级子企业 | 政策、战略、投资、销售收款、采购付款、资金、治理、内控 | 改革重组、用工分配、廉政 |
| 境外业务子企业 | 政策、战略、投资、境外投资、境外资产、资金、治理、内控 | 其他按业务 |
| 上市国有控股公司 | 政策、战略、投资、各上市股权模块、业务循环、治理、内控 | 环保、用工、风险合规 |
| 混改企业 | 政策、战略、投资、混改、治理、内控 | 其他按业务 |

## 五、审计报告四要素

> 类型：流程
> 来源：经济责任审计实务
> 置信度：实务经验
> 关联：internal_audit.md - 审计发现报告撰写

报告**应当**含四要素：

1. **总体评价**：写实评价或量化分等（好/较好/一般/较差）
2. **主要业绩**：工作思路、发展规划、重大举措及成果
3. **审计发现的主要问题和责任认定**：逐条问题 + 直接责任/领导责任认定
4. **审计建议**：针对原因、可操作、明确责任主体与整改时限

问题描述与法规匹配的公文化重述规范、语言规范，沿用 internal_audit.md「审计发现报告撰写」的五步转化与语言要求，不重复。
